V26.8.0 2026-07-31
🆕 RS-232 訊號狀態列

🚦 標題列下方新增一排訊號燈

握手訊號一目了然，輸出訊號還可以直接點燈號切換。

  • LOCAL (OUT)：BRK / RTS / DTR — 點燈號即切換輸出狀態，未連線時停用
    • 連線後、第一次點擊前顯示為未設定：瀏覽器只能設定輸出訊號、無法讀回目前狀態
    • 刻意不在連線時自動設定 DTR/RTS，以免觸發 ESP32／Arduino 的自動重置電路讓板子重開
  • REMOTE (IN)：DCD / DSR / CTS / RI — 唯讀，每 0.25 秒更新一次
  • ACT — 只要有資料進出就閃爍
  • ERR — 偵測到 Framing／Parity／Overrun／Break 錯誤時亮紅閃爍 3 秒，點一下可提前清除；錯誤發生後會自動恢復接收，不再像以前那樣直接中斷
⚠️ 關於同位元（Parity）錯誤
  • 目前連線一律使用 8N1（無同位元），因此同位元錯誤不可能發生，ERR 燈實際上只會對 Framing／Overrun／Break 有反應
  • 若要讓同位元錯誤能被偵測，需要先在介面上提供同位元／資料位元／停止位元的設定選項

V26.6.0 2026-07-31
🆕 重新整理後自動接回連接埠

🔄 重新整理頁面不用再手動按一次「連線」

只要上次那顆連接埠還插著，重新整理或重新開啟頁面時會自動接回去，連鮑率都一起還原。

  • 三個條件同時成立才會自動連線
    • 「自動重連」開關是開的
    • 上次不是你自己按「斷開」離開的（裝置被拔掉不算）
    • 那顆連接埠目前仍然存在且已授權
  • 找不到連接埠時不會持續嘗試連線，避免一開頁就霸佔連接埠，害 Arduino IDE 之類的程式連不上
  • 自動連線失敗只會留一行訊息，不會跳出整塊排錯提示
🔧 修正
  • 「自動重連」開關的狀態現在會被記住：原本關掉後重新整理又會變回開啟
  • 連接埠記憶一併記下鮑率，重新整理後鮑率跟著還原

    • 已連線時箭頭停用；點選單以外的地方會自動收合

🆕 版本編號制度變更

🔢 改用年度制版號 Va.b.c

自本版起，版本號改為年度制：a = 西元年後兩碼（2026 → 26）、b = 功能擴充編號、c = bug 修正編號；前段編號增加時，其後各段一律歸零。原語意版號 v3.0.1 為此制度前的最後一版。

  • 版號唯一來源移至 <title>：頁面標題為「NuMonitor for Serial Port V26.0.0」，程式啟動時自行解析
    • Header 的版本徽章改為執行時從 document.title 讀取，不再寫死
    • Console 初始化訊息同樣改用解析結果，避免多處版號不同步
  • 新增 backup/ 快照機制：每次改版前先將現行檔凍結為 NuMonitor4SerialPort_V<版號>.html，可隨時回滾（目前收錄 V1.8.0、V2.0.0、V3.0.1）
  • 新增 index.html 導向頁：以本地伺服器開啟專案目錄時會自動進入主程式，不必再手動指定檔名

🔄 變更 - 群組格式語法調整

📝 群組標示符號變更

數據群組格式的標示符號從方括號 [] 改為大括號 {}，提供更直覺的語法體驗：

舊格式：[群組名稱|最小值|最大值|圖表類型]Label:Value

新格式：{群組名稱|最小值|最大值|圖表類型}Label:Value

範例：{溫濕度|0|100|line}Temp:25.5,Humidity:60.2

  • 大括號在多數程式語言中更常用於結構化數據
  • 避免與陣列索引符號混淆
  • 視覺上更易於識別群組定義區塊

📊 即時繪圖功能開關

  • 關閉時僅顯示終端機文字，不進行圖表解析
  • 適用場景：大量數據傳輸時提升效能、只需查看原始數據時
