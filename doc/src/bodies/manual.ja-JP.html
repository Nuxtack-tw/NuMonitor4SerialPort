🎯 概要

NuMonitor は Arduino、ESP32、モデム、組み込み開発全般のためのシリアルポートモニタです。Arduino IDE のシリアルモニタを置き換えるもので、リアルタイムのグラフ描画、GPS トラッキング、RS-232 信号の完全な制御を備えています。すべては単一の HTML ファイルで、ブラウザから直接動作します。

インストール不要。 nuxtack-tw.github.io/NuMonitor4SerialPort でそのまま実行できます。HTML ファイルをダウンロードしてローカルで開いても構いません。

NuMonitor は Web Serial API の上に構築されており、この API は Chromium 系ブラウザにしか実装されていません。また セキュアコンテキスト が必要です。HTTPS、localhost、ローカルの file:// ページのいずれでも動作します。

ハードウェア

シリアルポートとして認識されるものであれば何でも使えます。Arduino ボード、ESP32 モジュール、USB シリアル変換器（CH340/CH343、CP210x、FTDI、PL2303）、携帯通信モデム、RS-232 ポートを備えた産業機器などです。NuMonitor は約 20 種類の代表的な USB シリアルチップを VID:PID で識別し、分かりやすい名前で表示します。

🚀 クイックスタート

手順 1 — NuMonitor を開く

公開版をそのまま開くか、ローカルにコピーした NuMonitor4SerialPort.html を開きます。インストールもビルドも不要です。

手順 2 — デバイスを接続する

  1. デバイスを USB ポートに挿します
  2. 接続 をクリックします
    • 初回：ブラウザのポート選択ダイアログが開くので、対象のデバイスを選びます
    • 2 回目以降：同じポートへ自動的に再接続され、ダイアログは出ません
  3. 別のポートを使うときは、ボタン右の ▾ をクリックして一覧から選びます。新しいデバイスを許可するには その他…（ブラウザの選択画面） を選びます
  4. 接続すると、ボタンは 緑色の「接続済み」 になり、ゆっくりと呼吸するように光ります。ポートメニューの矢印は消えます。ボタンにカーソルを乗せると赤くなり、クリックで 切断 できます
  5. デバイスが抜かれると、ボタンは オレンジ色の「接続中…」 になり、復帰するまで 1 秒ごとに再試行します。その状態でクリックすると再試行を中止します

手順 3 — ボーレートを設定する

デバイスに合わせた速度を選びます。Arduino のスケッチであれば Serial.begin() に渡した値です。選択できる速度は 300、1200、2400、4800、9600、19200、38400、57600、74880、115200（既定）、230400、250000、500000、1000000、2000000 ボーです。

ボーレートはポートと一緒に保存されるため、ページを再読み込みしても両方が復元されます。

文字化けする場合は？ ほぼ確実にボーレートの不一致です。ポートは 8N1（データ 8 ビット、パリティなし、ストップ 1 ビット）で開かれます。これは大多数のデバイスが使う設定です。

URL の自動検出

受信データに現れたリンクは自動的にクリックできるようになります。対象は https://、http://、www.（https とみなします）、ftp:// です。

行末コード

入力欄の右にあるセレクタで、送信するデータの末尾に何を付けるかを決めます。

選択肢送信されるバイト用途
なし（何も付けない）1 バイトずつ自分で制御する場合
LF\n（0x0A）readStringUntil('\n') を使う Arduino/ESP32 のスケッチ。既定値です
CR\r（0x0D）モデムの AT コマンド、および多くの CLI ファームウェア
CRLF\r\nWindows 系のデバイスや一部のモジュール
⚠️ モデムを扱うなら CR を選んでください。 AT コマンドはキャリッジリターンで終端します。LF や「なし」で送ると、モデムは終端待ちのまま止まり 何も応答しません。これは接続の失敗ではなく、コマンドが完結したと見なされていないだけです。

この設定は 記憶され、次にページを開いたときに復元されます。

🚦 RS-232 信号パネル

接続するとヘッダーの下にハンドシェイク信号の表示列が現れます。未接続のときは列ごと非表示になります。

LOCAL (OUT) — 自分の出力、クリックで切り替え

表示正式名称備考
BRKBreakブレーク状態にします。1 回目のクリックで開始、もう一度で解除します
RTSRequest To Sendハードウェアフロー制御を行うデバイスでは通常必要です
DTRData Terminal Readyほとんどのモデムは DTR がアサートされていないとコマンドを受け付けません

なぜ最初は消灯しているのか。 Web Serial API は出力信号を 設定 できますが 読み戻す ことができません。クリックするまで NuMonitor は本当にその状態を知らないため、ブラウザがオープン時に何をしたかを推測せず、正直に「不明」として表示します。

⚠️ Arduino・ESP32 をお使いの方へ： 多くの開発ボードでは DTR と RTS が自動リセット回路につながっているため、これらを操作すると ボードが再起動することがあります。NuMonitor は接続時にこれらの信号へ意図的に一切触れません。操作するかどうかは完全にあなたの判断です。

REMOTE (IN) — デバイス側の出力、読み取り専用

表示正式名称点灯の意味
DCDData Carrier Detectキャリア検出 — モデムが回線を確立しています
DSRData Set Readyデバイスに電源が入り、準備ができています
CTSClear To Sendデバイスがデータを受け付けられる状態です
RIRing Indicator呼び出し信号を検出しました

この 4 つは 250 ms ごとにポーリングしています。Web Serial API は信号変化のイベントを提供しないため、ポーリング以外の方法がありません。

ACT と ERR

  • ACT — どちらの向きであれバイトが流れるたびに点滅します。連続転送中は点灯しっぱなしに見えます
  • ERR — フレーミングエラー、パリティエラー、バッファオーバーラン、ブレーク受信のいずれかで赤く 3 秒間点滅します。クリックすれば早めに消せます。接続は 切断されず、受信は自動的に再開します

パリティエラーについて： 現在ポートは 8N1 で開かれます。パリティビットがなければパリティエラーは発生しないため、実際には ERR はフレーミング・オーバーラン・ブレークに反応します。

📈 プロッタ

自動解析

設定は不要です。デバイスから普通のテキストを出力するだけで、NuMonitor が何をグラフにするかを判断します。解析できる数値を 1 つ以上含む行はデータとして扱われ、それ以外はそのままターミナルのテキストとして表示されます。

グラフの操作

ボタン内容
一時停止裏でデータを受け取りながら、グラフの更新だけを止めます
スムージング折れ線グラフと面グラフを滑らかな曲線で描きます
クリアそのグループのデータを破棄します
CSVグループのデータを CSV ファイルとして書き出します
背景色グラフの背景色を指定します。グループごとに記憶されます
マップグループに map: 座標が含まれるときだけ現れます

X 軸カーソル

グラフの上でポインタを動かすと、その位置のサンプルにおける各系列の正確な値を読み取れます。

スクロールで拡大縮小

グラフ上でスクロールすると表示するサンプル数が 20 から 2000 まで変わります（既定は 100）。メモリには系列ごとに最大 500 サンプルが保持されます。

凡例の操作

凡例の項目をクリックするとその系列を表示・非表示にできます。色のマークをクリックすると色を変更でき、その色は記憶されます。

📊 グラフの種類

注意： map は有効なグラフ種別では ありません。{X|0|1|map} と書くと line に戻されます。マップは座標を含むタブに現れる表示切り替えです。

🗺️ GPS トラッキング

マップを有効にする

データ行に map:緯度,経度 を追加します。そのタブに 🗺️ ボタンが現れます。

座標の形式

形式例
十進度（負値可）map:25.051075,121.630951
十進度＋方位map:25.051075N,121.630951E
度・分map:25°3.0645'N,121°37.857'E
度・分・秒map:25°3'3.87"N,121°37'51.4"E

緯度 ±90 度、経度 ±180 度を超える座標は受け付けません。

マップの操作

  • 軌跡の点数 — 地図上に残す直近の位置の数。1 から 100 まで（既定は 10）
  • 追従 — 最新位置を常に中央に保ちます。オフにすると、地図が勝手に戻ることなく自由に移動・拡大できます
  • 軌跡のマーカーをクリックすると、その地点の座標と記録されたデータ値が表示されます

📝 データ形式リファレンス

完全な構文

{グループ名|Y軸最小|Y軸最大|グラフ種別}#カウンタ ラベル:値 ラベル=値 map:緯度,経度

各項目

項目必須備考
グループ名いいえタブになります。ラテン文字以外を含む任意のテキストが使えます
Y 軸最小 / 最大いいえ数値、または auto。解析できない値は auto として扱われます
グラフ種別いいえline area stack scatter bar gauge pie。それ以外は line に戻されます
#カウンタいいえ} の直後に置きます。X 軸のラベルになります。負数・小数も使えます
データ点はい解析できる数値が最低 1 つ必要です。なければその行はテキストのままです
map:いいえそのタブにマップ表示を追加します

データ点の書き方

Serial.println("Temp:25.5 Humidity:60.2"); // キー:値 — 推奨 Serial.println("Temp=25.5 Humidity=60.2"); // キー=値 Serial.println("25.5 60.2 1013.2"); // 数値のみ → CH1, CH2, CH3 Serial.println("Temp\t25.5"); // ラベル [タブ/空白] 値
  • 区切り文字：空白、カンマ、タブ
  • ラベルと値の区切り：: または =
  • 単位は自動的に取り除かれます — 25.5°C、60.2%、40.5km/h はいずれも先頭の数値として解析されます
  • 解析できないトークンは読み飛ばされ、行の残りは失われません

スケッチの例

// 単位とサンプル番号を付けた環境モニタリング void loop() { Serial.print("{Environment|0|100|line}#"); Serial.print(seq++); Serial.print(" Temp:"); Serial.print(readTemp(), 1); Serial.print("°C"); Serial.print(" RH:"); Serial.print(readRH(), 1); Serial.println("%"); delay(100); // 10 Hz } // 3 つのタブを同時に出す void loop() { Serial.print("{Temperature|15|35|line}Indoor:"); Serial.print(t1); Serial.print(" Outdoor:"); Serial.println(t2); Serial.print("{System|0|100|bar}CPU:"); Serial.print(cpu); Serial.print(" MEM:"); Serial.println(mem); Serial.print("{Battery|0|100|gauge}Level:"); Serial.println(bat); delay(500); } // GPS 軌跡付きのドローンテレメトリ void loop() { Serial.print("{Drone|0|120|line}#"); Serial.print(frame++); Serial.print(" Alt:"); Serial.print(alt, 1); Serial.print(" Speed:"); Serial.print(spd, 1); Serial.print(" map:"); Serial.print(lat, 6); Serial.print(","); Serial.println(lng, 6); delay(200); }

❓ FAQ

Q: ポートが 1 つも表示されません。

A: デバイスが挿さっているか、USB ドライバが入っているか、Chrome/Edge/Opera を使っているか、そして他のプログラムがポートを掴んでいないかを確認してください。よくある原因は Arduino IDE のシリアルモニタです。

Q: 文字化けしか出ません。

A: ボーレートが合っていません。デバイスの Serial.begin() と同じ値に設定してください。

Q: グラフが表示されません。

A: プロッタの切り替え（📊）がオンになっているか、その行に解析できる数値が 1 つ以上あるか、グループ数の上限 10 に達していないかを確認してください。

Q: モデムが AT コマンドにまったく応答しません。

A: 上から順に確認してください。

  1. 行末コードを CR にする — これが圧倒的に多い原因です。AT コマンドはキャリッジリターンで終わる必要があり、既定の LF ではモデムは応答しません
  2. 信号パネルから DTR をアサート します（モデムがハードウェアフロー制御を使うなら RTS も）。他の端末ソフトはオープン時に自動的にこれらを立てますが、NuMonitor は開発ボードのリセットを避けるため意図的に立てません
  3. DSR と CTS を確認 します。DSR が消灯なら電源が入っていないか配線が誤っています。CTS が消灯ならデータを受け付けていません
  4. ボーレートを確認 します
  5. エコー をオンにし、TX バイト数 のカウンタを見て、データが実際にパソコンから出て行ったことを確かめます

Q: 自動再接続と自動接続はどう違いますか。

A: 1 つのスイッチで 2 つの動作を制御しています。

  • 接続中にデバイスが抜かれた場合 → 戻ってくるまで 1 秒ごとに無期限で再試行します
  • ページを再読み込みまたは開き直した場合 → 前回のポートに再接続し、ボーレートも復元します

ページを離れる前に 自分で切断した 場合は、自動的に再接続することはありません。スイッチの状態自体も記憶されます。

Q: ESP32 の接続が不安定です。

A: ESP32 の USB CDC デバイスは、再起動するとポートオブジェクトが無効になることがあります。NuMonitor は古くなったハンドルを捨て、ブラウザからポートを取り直します。デバイスを選び直さなくても再接続できるのはこのためです。

Q: データを書き出すには？

A: グラフの操作列にある CSV をクリックすると、そのグループを書き出せます。

Q: テーマや言語はどこで切り替えますか。

A: 右上の月／太陽の切り替えと言語セレクタを使います。どちらも記憶されます。グラフとターミナルの配色はテーマに追従します。

マニュアル のリンクとバージョンバッジも画面の言語に追従します。このマニュアルは 12 言語で読めます。English、Deutsch、Français、Español、Português、Italiano、Türkçe、日本語、Tiếng Việt、Bahasa Indonesia、Bahasa Melayu、および 繁體中文 です。右上のセレクタから選んでください。まだ専用のマニュアルがない言語では英語版が表示されます。
